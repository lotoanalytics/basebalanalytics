# Baseball Analytics

Página de resultados de béisbol dominicano (LIDOM), Serie del Caribe y Clásico Mundial, con el estilo de LotoAnalytics.

- `index.html` — la página completa (un solo archivo). Se abre directo en el navegador.
- `INSTRUCCIONES.md` — decisiones, diseño, reglas y pendientes. **Léelo antes de cambiar algo.**

Vista de prueba: los juegos y números son de ejemplo hasta conectar una fuente real de datos.
